## 关键方法论发现：裁判首位偏置

10 次有效裁决中，胜者与"文本甲"（先呈现者）**10/10 完全一致**——裁判从未
选过"乙"。这是典型 LLM 裁判 position bias。本轮设计里每轮呈现顺序按种子
随机翻转，偏置在多数票层被顺序分布部分抵消（i1 甲序 2 crew：1 solo →
crew"胜"；i2 反之），因此**逐意图胜负不可信，只有"无法区分"这个整体结论
与成本数据可信**。

下轮必修（已知补救，按优先序）：
1. **一致性过滤**：同一对做正反两向呈现，仅两向一致才计有效票
   （position-consistent voting，业界标准做法）；
2. 裁判提示词显式申明"呈现顺序随机、与质量无关"；
3. 换更强裁判模型或双模型裁判交叉；
4. 维度分（scores）辅助判读——本轮已采集，复核见证据 JSON。

## 按预注册口径判读

预注册（PLAN v2）：胜率 ≥75% → 结构显著有效；40-60% → 简化优先；≤35% →
结构负收益。本轮有效信号为「不可区分 + 成本 3.8×」→ 落在**「优势不显著 →
重设计优先简化」**区间。这与重设计定稿（ARCHITECTURE-REVIEW 补记三）的
方向一致：**续写档（单笔者+全量状态注入）作为 ~80% 轮次的默认档**获得第
一份实证支持——单笔者在本套裁判下质量不落下风，而成本/延迟只有流水线
的 26%。

限定与诚实边界：
- 单模型自评（deepseek 写 deepseek 判）+ 首位偏置 → 质量结论只到
  「不可区分」为止，不支持「solo 更好」；
- fixture 双角色小卡、无长程 Campaign 状态积累——认知隔离与长线记忆
  维度未被本轮覆盖（那正是 sequential_crew/duet_merge 两臂要测的）；
- 每意图仅 1 样本/臂，无重采样方差估计。
