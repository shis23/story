# Import / Export Compatibility Hardening Plan

- Branch: `codex/import-export-hardening`
- Baseline: `main@c3a972d`
- Worktree: `C:\tmp\storyforge-import-export`
- No GUI or real LLM required

## Objective

Build a deterministic compatibility and loss-detection matrix for ST V2/V3 cards, PNG/JSON,
world books, regex scripts, MVU data and StoryForge Campaign bundles. Harden parsers and
roundtrips where evidence reveals loss or unsafe partial import.

## Required scope

1. Inventory supported ST fields, aliases, unknown-field preservation, character book routes,
   regex placements, alternate greetings, extensions and MVU schema/state.
2. Create sanitized/minimal fixtures plus generated edge cases; existing repository test cards
   may be used but no external user data may be added.
3. Add semantic roundtrip comparison: import -> internal -> export/serialize -> re-import,
   distinguishing intentional normalization from data loss.
4. Cover PNG metadata, JSON encodings/BOM, malformed/truncated input, oversized fields,
   duplicate names/ids, unknown extensions and hostile HTML/regex payloads.
5. Expand Campaign bundle roundtrip for definitions, instances, knowledge provenance,
   variables, tasks, conversations, variants, Turn/Attempt and Chronicle relationships.
6. Add deterministic fuzz/property tests with bounded seeds and reproducible failing cases.
7. Provide a machine-readable compatibility report generated by tests or a script.

## TDD and acceptance

- First capture current behavior with failing tests for every confirmed loss/corruption case.
- Corrupt input must fail without partial store mutation.
- Unknown compatible fields must survive where the format permits.
- Exported data must not silently flatten multi-character Campaign semantics into one card.
- All fixtures and reports must be secret-free and small enough for Git.

## Boundaries

- No real model calls and no Tauri GUI automation.
- Do not modify Turn lifecycle, SQLite backend, plugin host or release pipeline.
- Do not introduce a new public export promise where no product entry exists; document gaps.
- Do not edit `docs/HANDOFF.md`.

## Scoped gates

- domain, infra-import and affected campaign/bundle tests
- strict Clippy for affected crates
- bounded fuzz/property suite
- `git diff --check c3a972d..HEAD`
