## 实验设计

### 四臂（定稿 887 行定义）

| 臂 | 形态 | 实现状态 |
| --- | --- | --- |
| solo_writer | 单笔者 + 全量状态注入（续写档原型） | 可跑（上下文拼装复用 A 臂同源原语） |
| parallel_crew | 当前生产平行流水线（导演→子 Agent→编剧） | 可跑（`PipelineOrchestrator`） |
| sequential_crew | 顺序可见流水线（后者可见前者产出） | **未实现**——重设计实现对象 |
| duet_merge | 对手戏：场记 + 按拍交替续演 | **未实现**——重设计实现对象 |

首轮盲测跑前两臂（同时回答「多 Agent 值不值」）；后两臂实现后并入同一
矩阵（缺席臂在报告 absent_arms 显式列出，不伪装已测）。Writer 推理模式
（Disabled/Prompted/Native）作附加维度（定稿 §11）。

控制变量：同一 campaign 快照、同一意图序列、同一模型与采样参数、同一 token 预算级。
每轮各臂独立生成——都从同一轮初状态出发（不互相续写，避免路径依赖）。

### 素材与轮次

- 卡：命定之诗 + 卿卿（本机验收卡，STORYFORGE_CT_CARD_* env 指入）——
  已有完整导入/抽取链路与 campaign 构建配方（card_translation harness 复用）。
- 每卡 4 个意图（开场推进 / 冲突升级 / 多角色同场 / 约束回收），共 8 对样本。
- 模型：deepseek-v4-pro（两臂一致）；`STORYFORGE_LLM_TIMEOUT_SECS=600`。

### 双盲裁判

- 裁判模型：deepseek-v4-pro（独立会话，不知道臂身份）。
- 每对样本随机化 A/B 呈现顺序（种子记录进证据），裁判 3 次独立评审取多数。
- 维度（各 1-10 + 总体二选一胜负）：
  1. 角色一致性（persona/口癖/知识边界，多角色时人物区分度）
  2. 情节推进（是否响应意图、有效事件密度）
  3. 文风质量（叙事张力、重复率、AI 腔）
  4. 约束遵守（不越界代打用户、不出戏、格式干净）
- 裁判提示词不含「流水线/单发」字样，只标「文本甲/文本乙」。

### 产出与判读

- 证据 JSON（脱敏：分数/胜负/维度/耗时/token 用量，不含正文）写
  `artifacts/blind-ab/`；正文样本另存本地不入库。
- 判读口径（预注册，防事后挑数）：
  - 8 对中 A 臂胜 ≥6 → 多 Agent 结构显著有效，重设计以「保结构、降延迟」为纲；
  - 4-5 → 优势不显著，重设计优先简化（砍层级换速度）；
  - ≤3 → 结构负收益，重设计考虑单 Agent + 工具化（重大方向证据）。
  - 同时记录墙钟与 token 成本比（质量差 × 成本比 = 决策矩阵）。

## 风险与控制

- 中继稳定性：沿用流式工具循环与退避（第 5 轮验收已固化）；并发 ≤2。
- 裁判偏置：长度偏好是 LLM 裁判常见偏置——评分维度里显式声明
  「长度不是优点」，并记录两臂字数供人工复核。
- 单模型裁判风险：3 次多数投票 + 保留全部分数分布；若资源允许补 flash
  第二裁判做一致性抽检（Cohen's kappa 粗算）。
